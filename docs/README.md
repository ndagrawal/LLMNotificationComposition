# Documentation

This directory contains the documentation and research papers for the LLM-Based Notification Message Composition project.

## Research Papers

* **[LLM_Notification_Composition_ACM_Paper.pdf](./LLM_Notification_Composition_ACM_Paper.pdf)**: The primary research paper formatted according to the ACM `sigconf` template.
* **[LLM_Notification_Composition_arXiv.pdf](./LLM_Notification_Composition_arXiv.pdf)**: The research paper formatted for arXiv (single column, 10pt).
* **[LLM_Notification_Composition.docx](./LLM_Notification_Composition.docx)**: The research paper in Microsoft Word format.

## Presentations

* **[LLM_Notification_Composition_Slides.pdf](./LLM_Notification_Composition_Slides.pdf)**: The presentation slides in PDF format.
* **[LLM_Notification_Composition_Slides.pptx](./LLM_Notification_Composition_Slides.pptx)**: The presentation slides in PowerPoint format.

## Source Files

* **`latex/`**: The LaTeX source code for the ACM version of the paper.
* **`latex_arxiv/`**: The LaTeX source code for the arXiv version of the paper.
* **`figures/`**: The high-quality rendered Mermaid diagrams used in the paper and slides.
