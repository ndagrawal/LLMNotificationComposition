# Documentation

This directory contains the documentation and research papers for the LLM-Based Notification Message Composition project (v3).

## Research Papers

* **[LLM_Notification_Composition_ACM_Paper.pdf](./LLM_Notification_Composition_ACM_Paper.pdf)**: The primary research paper formatted according to the ACM `sigconf` template (v3).
* **[LLM_Notification_Composition_arXiv.pdf](./LLM_Notification_Composition_arXiv.pdf)**: The research paper formatted for arXiv (single column, 11pt, matching arXiv:2211.08209 style).
* **[LLM_Notification_Composition_v3_arXiv.pdf](./LLM_Notification_Composition_v3_arXiv.pdf)**: The v3 arXiv PDF (uploaded source).
* **[LLM_Notification_Composition_Paper.docx](./LLM_Notification_Composition_Paper.docx)**: The research paper in Microsoft Word format (v3).

## Presentations

* **[LLM_Notification_Composition_Slides.pdf](./LLM_Notification_Composition_Slides.pdf)**: The presentation slides in PDF format (v3, 20 slides).
* **[LLM_Notification_Composition_Slides.pptx](./LLM_Notification_Composition_Slides.pptx)**: The presentation slides in PowerPoint format (v3, 20 slides).

## Source Files

* **`latex/`**: The LaTeX source code for the ACM version of the paper (v3).
* **`latex_arxiv/`**: The LaTeX source code for the arXiv version of the paper (v3).
* **`figures/`**: The high-quality rendered Mermaid diagrams used in the paper and slides.

## What's New in v3

1. **Message Quality Framework** — Six-dimension definition (contextual relevance, clarity, actionability, novelty handling, linguistic freshness, persuasive appropriateness)
2. **Architectural Attribution** — Disentangles message generation from targeting/ranking/timing
3. **Binding-Constraint Framework** — Three-criterion decision framework for when to use (and not use) LLMs
4. Contributions reduced from 4 to 3 (more focused)
5. New Section 2: "Why Message Quality Is an Independent Optimization Target"
6. Five threats to validity (was four) — added Framework Limitations
